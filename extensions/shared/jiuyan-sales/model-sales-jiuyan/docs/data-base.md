### 4. SKU 维表 (SKU Dimension Table)

- **表名：** `dim_sku`
- **总 SKU 数：** **4,097 个**
- **字段包含：** 商品编码 (PK), 商品名称, 产品分类, 市场吊牌价, 基本售价, 首次/最近出现日期, 以及结构化规格字段 (`spec_length`, `spec_size`, `spec_hook`, `spec_qty`), **最新可用库存 (`latest_inventory`) 和采购在途 (`latest_in_transit`)**。
- **关联表：** `sku_tags` (存储商品的所有分类标签，如钩型、材质、适用场景等)。
- **更新逻辑：** 提取 `sales` 表最新非空元数据，并通过正则解析商品名称获取规格和标签。

---

### 5. 核心预测视图 (Core Forecasting Views)

为支持 LightGBM 模型，定义了以下视图：

- **`v_monthly_sku_sales`**: 月度 SKU 汇总，包含销量、均价、支付额及活跃店铺数。
- **`v_sku_region_profile`**: 计算每个 SKU 的 `top_province`（主要销售省份），用于捕捉地域季节性。
- **`v_training_base`**: 最终宽表，集成 SKU 规格、渠道、折扣率及地域画像，作为模型输入。

具体定义参见 `database/schema.sql`。
